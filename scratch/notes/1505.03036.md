## 1505.03036 Removing systematic errors for exoplanet search via latent causes
- 作者/日期/来源：B. Schölkopf, D. W. Hogg, D. Wang, D. Foreman-Mackey, D. Janzing, C.-J. Simon-Gabriel, J. Peters；2015-05-12；arXiv:1505.03036（ICML 2015 扩展版）
- **一句话定位**：提出「半同胞回归（half-sibling regression）」：利用受同一隐变量噪声影响的其他观测量，回归掉系统误差以重建不可观测的信号 Q，并用于 Kepler 系外行星测光去系统误差（CPM 的理论奠基文）。
- **研究问题**：感兴趣的量 Q 不可直接观测，只能看到被噪声 N 退化的 Y；N 同时影响另一组可观测量 X。能否借助 X 恢复 Q？
- **模型与方法**：因果图 N→Y, Q→Y, N→X（Q 与 N 独立，故 X⊥Q）。加性噪声假设 Y=Q+f(N)（f 不可观测输入）。关键观察：X⊥Q，故用 X 预测 Y 只能捕捉 N 的贡献；估计量 Q̂:=Y−E[Y|X]，即从观测中减去回归函数。因 X 与 Y 是同一隐父节点 N 的「半同胞」而得名。识别只能到规范自由度（Q 的可逆重参数化与均值）。
- **主要命题/定理**：Proposition 1（完全信息）：若存在 ψ 使 f(N)=ψ(X) 且 Q⊥X，则 f(N)=E[f(N)|X] 且 Q̂=Q−E[Q]（几乎必然）。Lemma 2：E[(Z−E[Z|X])²]=E[Var[Z|X]]。Proposition 3（不完全信息）：E[(Q̂−(Q−E[Q]))²]=E[Var[f(N)|X]]，误差恰为条件方差。Proposition 4：X^s=g(N)+s·R（R,N,Q 联合独立，g 可逆、f∈C¹_b），则 s→0 时 Q̂_s 依 L² 收敛到 Q−E[Q]。Proposition 5：观测 d 个 X_i=g_i(N)+R_i（各 R_i 独立、Σ var(R_i)/i²<∞、g̃_d=(1/d)Σg_j 可逆且逆一致等连续），则 d→∞ 时 Q̂_d 依 L² 收敛——即预测变量越多，各自独立信号平均掉，N 的重构越准。还讨论时间序列情形（图 2：时间 T 作混杂）与非效应情形（仅需 N 与 X 相关，不必 N→X）。实验：合成数据（随机 sigmoid 的 f、g，正态 N,Q,R）验证两个渐近行为；Kepler 数据上即 CPM：4000 个预测像素（约 150 颗同 CCD、星等相近、距离≥20 像素的星），每月约 1300 点单独训练，L2 正则加交叉验证，另加自回归分量（±9 小时排除窗外的 3 个过去+3 个未来点）；在 1000 颗星（500 随机+500 随机 G 型）上以 12 小时 CDPP 指标比较，CPM 整体优于 Kepler 官方 PDC 管线。
- **在因果研究脉络中的角色**：示范「因果结构启发机器学习」的代表作：不推断因果图，而是利用已知因果结构（独立恒星共享仪器系统误差）做去混杂；是加性噪声模型框架从因果发现向因果去噪/自校准（self-calibration）的延伸，直接催生了 1508.01853 的 CPM，并与因子分析类去混杂（基因表达 batch effect）传统相通。
