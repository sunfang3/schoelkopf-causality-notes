## 1509.08056 Discovery and Visualization of Nonstationary Causal Models
- 作者/日期/来源：Kun Zhang, Biwei Huang, Jiji Zhang, B. Schölkopf, Clark Glymour；arXiv v3 2016-06-18（刊于 IJCAI 2016）
- **一句话定位**：把时间/域索引 C 当作显式变量加入约束式因果发现，同时解决非平稳数据下三个问题：检出哪些变量的局部机制非平稳并恢复骨架、借分布变化定向某些边、以及用核方法可视化因果模块的非平稳性。
- **研究问题**：真实数据（fMRI、股价等）的生成过程随时间/域改变：忽略变化的因果模块会让 PC 类方法产生虚假边（模块共同变化等价于隐混杂 g(C)），把固定函数因果模型（如 LiNGAM）拟合到混合数据会使残差与原因不再独立（文中给出 V2=0.3V1+E 与 V2=0.7V1+E 两数据集合并的反例）。
- **模型与方法**：结构方程 V_i=f_i(PA_i, g_i(C), θ_i(C), ε_i)，其中 ε_i 互相独立且与 C 独立；隐混杂 g_l(C) 是 C 的光滑函数（「弱因果充分性」：给定 C 时混杂取定值），θ_i(C) 是变量特有的变参数，且各 θ_i(C) 互相独立。联合分布在增广图 G^aug（加入 g_l(C)、θ_m(C) 及指向 V_i 的箭头）上马尔可夫且忠实。Algorithm 1：在 V∪{C} 上跑约束式程序——V_i 与 C 条件独立（给其他变量某子集）当且仅当 V_i 的模块平稳；V_i 与 V_j 条件独立（给其余变量子集∪{C}）当且仅当在 G 中不相邻；条件独立检验须用非参数的核条件独立检验（KCI）而非偏相关。与 C 相邻的变量称为「C 特异变量」。方向判定：情形 1，V_l 不与 C 相邻时按无盾三元组 C→V_k−V_l 的 V 结构规则定向；情形 2，两端都与 C 相邻时依据「P(因) 与 P(果|因) 独立变化」原则，构造依赖度量 Δ̂_{V2→V1}=E log[ P̄(V1|V2)/⟨P̂(V1|V2)⟩ ]（式 14；KL 散度意义的冗余贡献，理论上 Δ≥0 且正确方向对应 θ'₁⊥θ'₂ 时为 0），用全数据核密度估计 P̄、滑动窗 KDE 估 P̂，取 Δ̂ 较小的方向为因果方向。可视化：定义非平稳性封装量 λ_i(C)=h_i(P(V_i|PA_i,C))，用条件分布的核嵌入（RKHS 算子 Û_{Y|X}）表示各时刻条件分布，再以第二层核构成 Gram 阵 M（式 16、17）做 KPCA 特征分解得低维 λ̂_i(C) 轨迹（Algorithm 2，KNV）。
- **主要命题/定理**：Theorem 1：在 3.1 节假设下，V_i 与 V_j 在 G 中不相邻 当且仅当 存在其余变量子集（可含 C）使二者条件独立——即 Algorithm 1 第 3 步骨架恢复渐近正确；证明利用 ε 联合分布不随 C 变、g 与 θ 均为 C 的决定函数，将条件作用中的 g(C)、θ(C) 替换为 C。Δ 的互信息分解（式 13）来自 Janzing 等的因果效应度量。实验：合成数据（5 变量 SEM，正弦/余弦时变参数 f1,f2,f3，w∈{5,10,20,30}，N=600/1000，10 次重复，SGS 搜索+KCI）验证骨架与非平稳模块检测优于忽略 C 的原方法；真实数据包括股价（6 只股票：识别非平稳模块与变点 T1,T2,T3，根因 2、4、5 的非平稳封装量与 3、6、7 的封装量呈现共同变点结构）和 fMRI 等。
- **在因果研究脉络中的角色**：把非平稳性从麻烦转为信息来源的代表工作：与「从分布变化定向」（利用 P(X) 与 P(Y|X) 独立变化）一脉相承，但首次处理原因与机制同时变化的情形；其核嵌入可视化给出非平稳因果模块的低维刻画，是 CdCD 等后续变化式因果发现方向的先声。
