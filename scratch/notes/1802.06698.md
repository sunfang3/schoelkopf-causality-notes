## 1802.06698 Analysis of cause-effect inference by comparing regression errors
- 作者/日期/来源：Patrick Blöbaum, Dominik Janzing, Takashi Washio, Shohei Shimizu, Bernhard Schölkopf；2018-02-19（v2 2019-01）；arXiv:1802.06698
- **一句话定位**：证明在适当独立性假设与近确定性条件下，将两变量等尺度归一化后，因果方向（cause→effect）的回归误差不大于反方向，据此提出只需双向回归并比较均方误差（Mean Squared Error, MSE）的因果方向推断算法 RECI。
- **研究问题**：二元无混杂情形下（X→Y 或 Y→X），能否仅凭观测数据的双向最小二乘误差不对称性识别因果方向，而无需独立性检验或加性噪声假设。
- **模型与方法**：设原因 C 与效应 E 取值于 [0,1]。取 φ(c) = E[E|c]，定义残差 N := E − φ(C)（不要求 C⊥⊥N，故允许噪声与原因相关，比加性噪声模型（Additive Noise Model, ANM）更一般），并考虑噪声水平族 E_α = φ(C) + αN，重缩放为等尺度的 Ẽ_α。技术假设：φ 严格单调递增二阶可微且 φ(0)=0, φ(1)=1；C 与 N 紧支撑；E[Var[N|C]] = 1。核心的「独立性公设」（式 7/8）：在 [0,1] 均匀概率空间上 Cov[φ′, Var[N|c]·p_C] = 0，即函数斜率与「条件方差×原因密度」不相关——其依据是模块化/自主性思想：φ 作为自然定律不包含关于 p_C 与噪声分布的信息；ANM 情形下退化为已知的 Cov[φ′, p_C] = 0（IGCI 类条件）。
- **主要命题/定理**：Lemma 1（方差比的极限）：lim_{α→0} E[Var[C|Ẽ_α]] / E[Var[Ẽ_α|C]] = ∫₀¹ φ′(c)^{−2} Var[N|c] p_C(c) dc。Theorem 1（误差不对称性）：在假设 1–4 下该极限 ≥ 1，且仅当 φ 为线性时取等号；证明经两次 Cauchy–Schwarz 不等式与独立性公设（式 10：∫ φ′ Var[N|c] p_C dc = 1）。几何直觉：近确定性关系的散点图像一条粗线，横竖方向宽度之比约为斜率平方。算法 RECI（Algorithm 1）：重缩放数据→双向拟合同一函数类回归→MSE 小者为因果方向；实验采用 logistic、单项式、多项式、线性 SVR、神经网络等回归器。经验结果：(1) 人工数据（Mooij et al. 2016 的 SIM/SIM-c/SIM-ln/SIM-G 及自造的线性/可逆非线性/不可逆非线性、输入与噪声强相关数据）：除近高斯的 SIM-G（紧支撑假设被违反，IGCI-高斯参考最优）外，RECI 用简单 logistic 或多项式回归即胜过 SLOPE、IGCI、CURE 与 LiNGAM，ANM 整体最佳；噪声 α 增大时各方法退化而 RECI 相对稳健，不可逆函数情形优势更大；(2) 真实数据（Tübingen cause-effect pairs 基准 100 个带权数据集）：SLOPE 与 RECI 显著优于 ANM、PNL、IGCI、CURE、LiNGAM，原始数据 SLOPE 略优，剔除低密度孤立点预处理后 RECI 最佳——且最优回归器竟是简单的 ax²+c 单项式，支持「欠拟合反而放大反向误差」的猜想；(3) 式 (23) 用误差比定义置信度，误差比可作拒绝决策的阈值。
- **在因果研究脉络中的角色**：把「因果方向描述更简单」（算法信息论不等式 K(p_C)+K(p_{E|C}) ≤ K(p_E)+K(p_{C|E})）的直觉转化为「因果方向回归误差更小」这一可检验命题，是 RECI 类基于回归误差的方法的理论奠基；与 IGCI（确定性极限）、ANM/PNL（独立性检验）、SLOPE（MDL 描述长度）同属二元因果发现的非条件独立路线，计算代价极低。
