## 1803.00810 Detecting non-causal artifacts in multivariate linear regression models
- 作者/日期/来源：Dominik Janzing, Bernhard Schölkopf；2018-03-02；arXiv:1803.00810
- **一句话定位**：在高维线性回归 X→Y 情形下，利用回归系数向量相对预测量协方差矩阵 Σ_XX 的「非典型取向」，提出检测关联究竟是因果影响、还是混杂（confounding）或过拟合（overfitting）造成的伪象的方法。
- **研究问题**：已知 d 维变量 X=(X_1,…,X_d) 与目标 Y 显著相关且先验排除 Y→X，如何从观测数据判断该相关是否无混杂——这是变量选择等后续因果推断的前提问题；沿用独立机制（independent mechanisms）原理：纯因果时 p_X 与 p_{Y|X} 互不包含信息。
- **模型与方法**：受独立成分分析（Independent Component Analysis, ICA）启发，设 ℓ 个不相关单位方差源 Z 组成混杂，结构方程为 X = MZ，Y = a^T X + c^T Z（a 为因果效应，c 为混杂耦合）。回归得到 a′ = Σ_XX^{-1}Σ_XY = a + M^{-T}c，其中 M^{-T} 放大 M 的小奇异值方向，故混杂项集中在 Σ_XX 小特征值子空间。混杂强度定义为 β = ‖a′−a‖²/(‖a‖²+‖a′−a‖²) ∈ [0,1]（0 纯因果、1 纯混杂）。关键假设：a、c 的分量独立取自旋转不变高斯先验（标准差 σ_a、σ_c），仅比值 θ = σ_c²/σ_a² 重要。估计流程：由样本得 Σ_XX、Σ_XY 与 â′，用 â′ 方向的似然估计 θ，再由大数定律近似（式 11）换算 β̂。
- **主要命题/定理**：Definition 2 与 Theorem 1（模型等价）：â′ 与 √(σ_a²I + σ_c²Σ_XX^{-1}) b（b 为标准高斯）同分布，因此推断只需 Σ_XX 与 d，无需知道 M、ℓ。Theorem 2（方向密度）：â′ 归一化方向的对数密度为 ½[log det R_θ − d log⟨ṽ, R_θ^{-1}ṽ⟩]，其中 R_θ = I + θΣ_XX^{-1}。Theorem 3（集中测量，concentration of measure）：d 大时单个 â′ 实例即可高概率近似对数似然值，误差随 d→∞ 趋于 0。第 5 节给出无混杂检验 θ=0 的统计量 T(ṽ) = (1/√d)(⟨ṽ, Σ_XX^{-1}ṽ⟩ − τ(Σ_XX^{-1}))，它在 θ=0 处与得分函数成比例，零分布近似为混合 χ² 分布；第 6 节证明过拟合产生同样效应——Y 与 X 独立、样本量不足时，无正则化的 â = M^{-T}y′ 同样集中于小特征值子空间，故混杂与过拟合在该检验下不可分但可统一检出。经验结果：模拟数据（d=ℓ=10~100，n=10000）中 β̂ 与真值 β 明显相关且随 d 增大改进，β 接近 0 或 1 处估计最好；β>0.6 时无混杂检验在置信水平 0.05/0.1 下大多被拒绝；d=10 时 n=20 会因过拟合大量误拒，需 n≈10000 才使 p 值近均匀。真实数据：光学装置（3×3 图像亮度，β 已知）中 β̂ 与真值显著相关但倾向低估（β=1 与 β=0 两例得 β̂=0.768 与 0）；红酒口感数据全变量时 β̂=0，剔除主导变量酒精后 β̂=0.62，合理；MEG 数据 10 个通道轮流作目标，得 β̂ = 1.0×7、0.6、0.1、0.0。
- **在因果研究脉络中的角色**：是 Janzing–Schölkopf 2017 一维混杂检测向多维的推广，属「用 p_X 与 p_{Y|X} 之间的非典型依赖探测混杂」路线；揭示了混杂与过拟合在高维回归中的共同几何签名（回归向量向低特征值子空间集中），暗示正则化与混杂校正的深层联系，并体现集中测量效应在因果推断中的作用。
