1903.01672 Causal Discovery from Heterogeneous/Nonstationary Data with Independent Changes

  • 作者/日期/来源：Biwei Huang, Kun Zhang, Jiji Zhang, Joseph Ramsey, Ruben Sanchez-Romero, Clark Glymour, Bernhard Schölkopf / 2019-03 (v5: 2020, JMLR 21:1–53) / arXiv:1903.01672
  • 一句话定位：提出 CD-NOD 框架，把跨域/时变的分布偏移（distribution shift）作为因果发现的资源：用代理变量 C（域或时间指标）恢复因果骨架、利用”因果模块独立变化”原理定向，并提取非平稳性的低维”驱动力”表示。
  • 研究问题：异质/非平稳数据的生成机制随域或时间变化，直接套用固定因果模型的约束法（PC/FCI）会产生伪边（相关变化形同隐藏混杂），功能因果模型（如 LiNGAM）在合并数据上残差不再独立。如何反而利用分布变化识别哪些机制在变、骨架、方向，并刻画变化本身？
  • 模型与方法：SEM 为 V_i = f_i(PA_i, g_i(C), θ_i(C), ε_i)，其中 C 为域/时间指标，θ_i(C) 是随 C 变化的机制参数，g_i(C) 为”伪混杂（pseudo confounder）“——可写成 C 的（光滑）函数。假设 1（伪因果充分性）、假设 2（增广图 G^aug 上的 Markov 与忠实性）。Phase I（Algorithm 1）：在 V∪C 上做（核条件独立 KCI）检验，与 C 相邻的变量即机制变化者，且给定 C 后 V 内条件独立关系与真实因果结构一致。Phase II 定向：情形 S1 用含 C 的无盾三元组（不变性的推广：P(V_i|S) 不变 ⟺ V_i⊥⊥C|S，涵盖 Hoover/Tian–Pearl/ICP 类方法）；情形 S2（两端都随 C 变）用独立变化原理——无混杂时 P(cause) 与 P(effect|cause)（即 θ_i(C) 与 θ_j(C)）独立变化，而反向分解 P(V₂)与P(V₁|V₂) 的变化参数一般相依；通过构造虚拟联合分布 P̃(Y,X|C=c)=P(Y|X,C=c)P(X) 的核嵌入（Proposition 1 给出免滑动窗口的全数据估计）与扩展 HSIC 度量模块间依赖来定向。KNV：对条件分布嵌入的 Gram 矩阵做特征值分解，得到非平稳”驱动力”的低维可视化，同样不依赖窗口分割。
  • 主要命题/定理：Theorem 1：在假设 1、2 下，V_i 与 V_j 在 G 中不相邻 ⟺ 给定 {其余变量}∪{C} 的某子集条件独立（骨架渐近可恢复，如同隐藏变化因子已知）。Theorem 2：相邻变量对的方向可识别，若满足其一：(1) 该边参与 V 结构；(2) 至少一方机制变化（双方都变则需独立变化）；(3) 存在只邻接其中一方的第三条边。Corollary 1 给出全图可识别的相应条件。实验：合成数据、star/plus 任务 fMRI（25 个 ROI，500 ms 分辨率，恢复的方向与已知视觉/运动通路一致）、港股与美股数据（驱动力与市场事件对应），并与 PC、LiNGAM 等基线比较占优。
  • 在因果研究脉络中的角色：把”独立因果机制（independent causal mechanisms）“原则从静态的可检验性困境中解放出来——模块独立只有在变化中方可在有限样本中检验；论证非平稳性/异质性等价于一类软干预（soft intervention），是”分布偏移携带因果信息”这一路线（ICP、多域因果发现）的集大成与非线性、非参数化推广。
