## 2007.02938 Causal Feature Selection via Orthogonal Search
- 作者/日期/来源：Ashkan Soleymani, Anant Raj, Stefan Bauer, Bernhard Schölkopf, Michel Besserve；2020-07-06（v3 2022-09-17，TMLR 2022）；arXiv:2007.02938
- **一句话定位**：提出 CORTH Features 算法，借用去偏/双重机器学习（Double/Debiased ML）的正交化思想，用"一对其余"的逐变量扫描在高维、非线性、允许环的数据中找出响应变量的全部直接因果父节点，计算代价仅为维度 d 的多项式级。
- **研究问题**：在大量协变量 X 中识别响应 Y 的直接因果父节点。已有方法（PC、LiNGAM 等）随变量数至少指数增长、难推广到非线性与有环情形。
- **模型与方法**：结构方程模型（SEM）设定：X∈R^d 的 d 个方程可唯一求解、允许非线性与环、协变量间允许隐混杂；Y 由线性结构方程 Y=⟨θ,X⟩+U 生成，U 与其他外生变量独立（即 Y 无隐混杂、无 X 是 Y 的后代；记假设 LDC 与 NFD；θ_j≠0 当且仅当 X_j 是直接父节点）。核心是把"θ_j 是否为零"化为非参数估计量 χ_j = E[(Y−E(Y|X_{−j}))(X_j−E(X_j|X_{−j}))]（式 2–3），对每个变量轮流做一对其余划分 D=X_j、Z=X_{−j}，按 Double ML 的 Neyman 正交分数 ψ=(Y−Dθ−g(Z))(D−m(Z))，用交叉拟合（K 份子采样）的 Lasso 估计 nuisance 函数 m、g，得到 χ̂_j 及其方差，再用正态检验 χ̂_j≈N(0,σ̂²/n)（Bonferroni 多重校正）判定 X_j 是否入选。
- **主要命题/定理**：Proposition 2：在允许 X_k 与 Z 之间非线性、有环、混杂赋值的图（图 2）下，正交分数 ψ(W;θ,β)=(Y−X_kθ−X_{−k}^⊤β)(X_k−r_{XX_{−k}}X_{−k}) 满足 Neyman 正交条件——正交性不依赖 X_k 与 Z 间因果方向。Proposition 3：条件 (13)–(15)（U 零均值、条件期望为零、E[(X_j−E(X_j|X_{−j}))²]≠0）下，(a) χ_j=θ_j·E[(X_j−E(X_j|X_{−j}))²]，且 j 是父节点当且仅当 χ_j≠0；(b) χ_j 具有双重稳健性，可用正则化方法估计条件期望。Proposition 5（近似线性稀疏类 ALS 假设等条件下）：交叉拟合估计满足 √n 收敛 χ̂_j→D N(χ_j, σ²/n)，给出 95% 水平的检验。计算复杂度：加速坐标下降下迭代 O(d κ_max log(1/ε))、每次 O(nd)，整体为 d 的多项式。实验：自建 72000 个模拟 DAG（不同节点数、连通度、噪声、非线性概率、样本量），与 LiNGAM、order-independent PC、rankPC、rankFCI、Lasso、Debiased Lasso、Markov Blanket 发现方法比较，CORTH Features 在各种噪声水平下精度均最高，尤其在协变量间非线性交互时显著占优，尽管数据生成条件偏向基线。
- **在因果研究脉络中的角色**：把 Double ML 从"已知处理变量的因果效应估计"推进到"因果发现/特征选择"，规避了忠实性与无环假设，是目标中心（target-centric）因果特征选择与半参数估计理论交汇的代表性工作。
