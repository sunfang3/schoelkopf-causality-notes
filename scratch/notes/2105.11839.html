2105.11839 DiBS: Differentiable Bayesian Structure Learning

  • 作者/日期/来源：Lars Lorch, Jonas Rothfuss, Bernhard Schölkopf, Andreas Krause / 2021-05-25（NeurIPS 2021）/ arXiv:2105.11839
  • 一句话定位：把贝叶斯结构学习（推断贝叶斯网络图结构的后验分布而非单个图）转移到隐概率图表示的连续空间做全可微推断，首次实现「图结构+条件分布参数」的联合后验推断，从而支持神经网络条件分布等非线性贝叶斯网络。
  • 研究问题：后验 p(G,Θ|D) 的推断需在超指数多 DAG（d 节点有 O(d!2^{d(d-1)/2}) 个）上进行；主流 MCMC 与 bootstrap 都把 Θ 积分掉，要求边际似然 p(D|G) 有闭式，被锁死在线性高斯/分类 BN；如何绕过共轭限制、用上梯度推断工具？
  • 模型与方法：引入隐变量 Z=[U,V]（两个 k×d 节点嵌入矩阵），生成模型 p(Z)p(G|Z)p(Θ|G)p(D|G,Θ)。图由双线性模型生成：p_α(G|Z)=∏_{i≠j}σ_α(u_i^Tv_j)（逐边概率，α 逆温度）；无环性不进似然而进先验：p_β(Z)∝exp[−β·E_{p(G|Z)}[h(G)]]·∏N(z_ij;0,σ_z²)，h(G)=tr((I+G/d)^d)−d 为 NOTEARS/DAG-GNN 型约束（β→∞ 时只生成 DAG），稀疏等图先验可并入。推断目标换成 p(Z|D)/p(Z,Θ|D)；似然对 G 可微时用 Gumbel-softmax 重参数化（式 12），否则用带基线的得分函数估计器（式 14，BGe 属此类）。用斯坦变分梯度下降（Stein Variational Gradient Descent, SVGD）传输 M 个粒子，核为 Z、Θ 两段高斯核之和；退火 α,β→∞ 后把 Z 映为离散图 G∞(Z)（u_i^Tv_j>0 即有边）。单粒子特例退化为 MAP 梯度上升、近似 NOTEARS；DiBS+ 按未归一化后验概率给粒子加权（自承无严格理论依据）。
  • 主要命题/定理：Proposition 1（隐后验期望等价）：E_{p(G|D)}[f(G)] 与 E_{p(G,Θ|D)}[f(G,Θ)] 均可写成对 p(Z|D)/p(Z,Θ|D) 的自归一化重要加权期望，推断 Z 不损失一般性。Proposition 2（隐后验得分）：给出 ∇_Z log p(Z|D)、∇_Z log p(Z,Θ|D)、∇_Θ log p(Z,Θ|D) 的解析形式，期望可蒙特卡洛估计。实验（Erdős-Rényi 与 scale-free 图，d∈{20,50}、期望 2d 边、N=100 观测、30 个 BN、30 个后验样本）：(i) BGe 边际推断中 DiBS+ 在 E-SHD、neg. MLL/I-MLL 上优于 BPC、BGES、MC3；(ii) 联合后验（对照 M-MC3、G-MC3、BPC、BGES）全指标最佳；(iii) 非线性高斯 BN（条件均值由 2 层 ReLU 网络给出，|Θ|=2220）为文献首次贝叶斯式推断，全面优于 MCMC 基线；(iv) Sachs 蛋白网络（11 蛋白、N=7466）：BGe 版 DiBS 置信最校准（AUROC 0.647），非线性联合推断 E-SHD 22.6 最接近共识网络；GPU 耗时秒到几分钟。
  • 在因果研究脉络中的角色：把 NOTEARS 式连续松弛从点估计提升为贝叶斯后验推断，补上「与贝叶斯结构学习的连接」；直接服务主动因果发现主线——后验是计算干预期望信息增益（如 von Kügelgen et al. 最优实验设计）的前提；SVGD 本身是核方法（RBF 核上的 Stein 恒等式），延续组的核与分布嵌入传统。
  • 本文自认的局限/未来工作：（1）SVGD 渐近运行时随粒子数二次增长，可换其他依赖得分的采样方法改进；（2）尚未处理缺失与干预数据，未做摊销式推断以利用富非结构化数据；（3）DiBS+ 粒子加权缺理论保证；（4）d=50 的 BGe 边际推断中得分函数估计器方差高、需更多样本；（5）偶有粒子返回含环图需丢弃；（6）因果解读依赖不可检验假设（如无未测混淆），安全关键应用须谨慎。
