## 2311.08605 Exploring the Jungle of Bias: Political Bias Attribution in Language Models via Dependency Analysis
- 作者/日期/来源：David F. Jenny、Yann Billeter（共同一作，ETH Zürich）、Mrinmaya Sachan（ETH）、Bernhard Schölkopf（MPI Tübingen）、Zhijing Jin（MPI+ETH，共同指导，源自本科论文）；v1 2023-11-15，v2 2024-05-12 / arXiv:2311.08605
- **一句话定位**：把因果公平性分析（causal fairness analysis）的标准公平模型搬进 LLM 内部——用提示工程从 ChatGPT 中抽取潜在的混杂与中介属性，再用活动依赖网络（Activity Dependency Network, ADN，基于偏相关的非参数依赖图）刻画这些属性如何影响 LLM 对美国总统辩论论证质量的打分，从而把「民主党候选人得分更高」的差异待遇部分归因于中介/混杂级联与模型失准（misalignment），而非直接的党派歧视。
- **研究问题**：LLM 偏见研究多停留在下游表现，内部成因不清；去偏方法要么流于表层（词嵌入几何去偏被证浅显）、要么过猛（Gemini 过度去偏扭曲历史）。在标准公平模型（Zhang & Bareinboim 2018：受保护属性 X→结局 Y，中介 W，混杂 Z；区分直接歧视 X→Y、间接因果 X→W→Y、间接虚假 X←Z→Y）下，LLM 的 W 与 Z 集合未知且黑箱不可得——如何近似抽取并刻画这些属性对决策过程的影响？
- **模型与方法**：案例设定：X=演讲者党派，Y=LLM 对论证质量的 Score 评分。数据：CPD 官方 1960 年以来 47 场美国总统/副总统辩论转录（5 万句、81 万词），切成 2500 BPE token（约 1875 词、10% 重叠）的片段，随机抽 150 片段、122 位演讲者；模型 gpt-3.5-turbo-0613、温度 0，共 8 万余次 API 查询、逾 2 亿 token。方法三步：(1) 参数化——依话语质量/论证质量文献（Steenbergen 2003、Wachsmuth 2017、Vecchi 2021）定义 103 个演讲者属性（如 Clarity、Respectfulness、Evasiveness）+5 个片段属性+21 个情境属性（如 Debate Year），每属性用多种问法（measurement types）测量，问法间发散度可评估提示可靠性；(2) 测量——提示 LLM 按 0–1 填 JSON 打分；(3) 网络估计——ADN（Kenett 2012）：节点为属性，边权由偏相关定义：PC^j_ik=(C_ik−C_ij·C_kj)/√((1−C²_ij)(1−C²_kj))（式1），影响矩阵 D_ij=Σ_{k≠j}(C_ik−PC^j_ik)/(N−1)（式2），非对称、无需参数化模型。验证两途：2000 次 bootstrap（Table 1：取 top-10/50/100/1000 边，一致性 0.85–0.90，边强 STD≈0.02）；以及属性扰动（在提示中把给定属性值 ±0.1 后看目标属性变化），扰动测度与 ADN 图式吻合（图8），但二次方开销只能验证个别连边。
- **主要命题/定理**：无定理，核心为经验发现：(i) 纯相关的偏见估计不可靠——Score 与 Speaker Party 的相关强烈依赖 Score 的具体定义（argue/argument/quality/voting 问法结果迥异；voting 问法明显异于其他，图9）；民主党候选人平均得分更高（图5）；(ii) ADN 中 Speaker Party 与 Score 之间缺乏直接连边（图6/7），提示直接歧视估计被夸大，观察到的是经由属性级联的间接影响（如 Clarity→Decorum、Interruptions→Respectfulness）；且党派与属性的相关可能源于政治进程的自选择，存在连边本身未必是偏见；(iii) 失准证据：LLM 评分聚焦论证的形式品质（客观性、可及性、连贯性），而情感属性对投票的重要性未在图中体现（图7），说明其与现实的对齐不完全——若被忽略的属性恰好与某党强相关，就会产生差异待遇而无「根本性党派偏好」；(iv) 讨论推论：天真微调去偏相当于对决策网络做非模块化干预（图1：对齐 f(B|A) 可能不加区分地改变本已对齐的 f(C|A)），基础模型无法逐一评估下游任务，去偏必须先做细致的偏见归因。
- **在因果研究脉络中的角色**：属 Schölkopf 组因果公平性与因果+NLP 两条支线的交汇——把 Zhang–Bareinboim 公平图、Plecko–Bareinboim 公平归因的形式语言用于 LLM 这一新对象，与组内反事实公平、追索（recourse）研究共享「区分直接/间接/虚假歧视路径」的方法论；对微调去偏的批评隐含独立因果机制（ICM）直觉：违反模块性的干预会外溢到无关关联。
- **本文自认的局限/未来工作**：(1) 提示抽取 LLM 属性类似社会调查，虽以多问法护栏，仍有改进空间；(2) ADN 表达能力与可靠性有限，未来引入其他网络估计方法；(3) 未来工作清单：分析微调与现有去偏策略对 ADN 的影响、预测微调效应的方法、对决策过程做定向修改的技术、跨 LLM 比较分析、深入扰动方法、从嵌入（甚至 GPT-4 迭代自动生成属性集）提取规范属性、其他数据类型（如 AI 对图像审美的感知）、生成与分类任务一致性检验、对演讲者简历（姓名、族裔、职业）的敏感性分析；(4) 承认结果有被滥用于操纵 LLM 输出偏见的风险。
