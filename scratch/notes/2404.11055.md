## 2404.11055 Do LLMs Think Fast and Slow? A Causal Study on Sentiment Analysis
- 作者/日期/来源：arXiv:2404.11055（v2 2024-10-27，EMNLP 2024 Findings 方向的工作）；Zhiheng Lyu*, Zhijing Jin*（港大/MPI 多伦多），Fernando Gonzalez（ETH），Rada Mihalcea（密歇根），Bernhard Schölkopf（MPI Tübingen），Mrinmaya Sachan（ETH）
- **一句话定位**：把文档级情感分析（sentiment analysis, SA）重新表述为「二元因果发现（causal discovery）+ 预测」两件事——借用 Kahneman 快/慢思维与峰终定律（peak-end rule）从观测数据判定评论 X 与情感 Y 的因果方向（X→Y 慢思维 vs Y→X 快思维），再用与数据因果方向对齐的「因果提示（causal prompts）」给 LLM 归纳偏置，零样本五分类 F1 最高提升 32.13。
- **研究问题**：SA 数据中评论与星级哪个是因、哪个是果无法事后追踪用户验证；已有「因果对齐（causal alignment）」研究（半监督只在反因果方向有效、对齐降低柯氏复杂度等）均针对从头训练的模型，LLM 时代（混合方向数据+提示式预测）因果对齐是否仍能改进性能？
- **模型与方法**：二元 cause-effect 设定：C1: Y:=f_Y(X,N_Y), N_Y⊥X；C2: X:=f_X(Y,N_X), N_X⊥Y（结构因果模型 SCM 形式）。操作性化：对评论 x 的 n 个句子用 DistilBERT-SST2 逐句打分（逆 sigmoid 截断到 [−10,10]）构成情感弧（emotion arc）e=(s₁,…,s_n)；慢思维预测 ŷ_avg=句均值，快思维预测 ŷ_peakEnd=(Peak(e)+s_n)/2，其中 Peak 取离中性 3 最远者；对齐分数 λ₁=|y−ŷ_avg|、λ₂=|y−ŷ_peakEnd|，λ_i 更小者归入因果过程 Ci。因果提示：C1 提示讲述"先写评论再仔细定星级"，C2 提示讲述"先选星级再写评论解释"（各 5 个 GPT-4 改写变体取平均）。
- **主要命题/定理**：无定理，为实证研究。(1) 因果发现：Yelp 34,851 条（C1 56%/C2 44%）、Amazon 2,582 条（54%/46%）、App Review 9,696 条（39%/61%），C1/C2 大致均衡；附录 B.2 KS 检验两子集的 λ₁、λ₂ 分布显著不同（p=8.5e-71、1.4e-11）。(2) Q1（标准提示下差异）：Yelp-5 测试集随机 1K 样本、7 个 LLM（GPT-2 XL 到 GPT-4），几乎所有模型在 C2 子集上更好（如 GPT-3 整体 F1 52.71，C1 43.96 vs C2 65.40），即 LLM 决策模式更接近快思维。(3) Q2（因果提示）：Data=C2+Prompt=C2 几乎全面最优，C2 数据上 Prompt C2 比标准提示 GPT-2 提升 32.13 F1（48.50 vs 16.37）、GPT-4 提升 14.23；但 Prompt C1 并非总帮助 C1 数据。(4) Q3（机制检验）：用因果追踪（causal tracing, Meng et al. 2022）对 LLaMa-7B/Alpaca-7B 各 100 样本归因：Prompt C1 下各句归因较均匀，Prompt C2 下峰句因果效应高于均值（LLaMa +3%、Alpaca +39%），但无模型充分关注"末句"——峰终定律只被部分内化。
- **在因果研究脉络中的角色**：直接延伸 Jin, von Kügelgen, Ni, Vaidhya, …, Schölkopf (EMNLP 2021)「数据收集的因果方向影响 NLP」与 Lyu et al. (UAI 2022 CRL Workshop) LLM 能否辨因故果的实证线；把 Schölkopf 组的因果/反因果学习理论（半监督不对称性）首次搬进 LLM 提示范式，属"因果思想用于理解与改进大模型"这条应用支线，而非新的因果识别理论。
- **本文自认的局限/未来工作**：(1) LLM 迭代快，只覆盖写作时的一组模型，呼吁在更多 LLM 与更多 SA 数据集上验证；(2) 心理学理论若更新，λ 值计算需随之修订（尽管因果提示的有效性佐证了当前设定的合理性）；(3) 因果图仅限二元基本情形，未来应纳入混淆因子、中介变量、碰撞变量；(4) 作为范式转换性质的工作，留有大量扩展：不同语言/场景的 SA 因果性质、方面级情感分析（ABSA）等。
