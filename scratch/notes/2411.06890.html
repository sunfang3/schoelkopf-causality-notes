2411.06890 SPARTAN: A Sparse Transformer World Model Attending to What Matters

  • 作者/日期/来源：arXiv:2411.06890（2024-11-11，v3 2025-12）；Anson Lei（Oxford）、Bernhard Schölkopf（MPI Tübingen）、Ingmar Posner（Oxford）；NeurIPS 2025

  • 一句话定位：在对象因子化（object-factored）的 Transformer 世界模型上施加硬注意力（hard attention）与稀疏正则，从图像观测联合学习随状态变化的局部因果图与动力学，并经干预 token 实现对未知干预的少样本自适应。

  • 研究问题：VCD/AdaRL 类方法学固定全局图，而物理交互时间稀疏、全局图近全连接；CoDA 主张软注意力加阈值，复杂观测场景会漏边/错边；ELDEN、FCDL、CAI 只能处理标量状态。目标：在对象嵌入、对象数目可变场景做局部因果发现并保持预测精度。

  • 模型与方法：训练数据来自多环境 {x0,…,xT, I}（I 为环境索引，干预如改重力，目标未知）。对象 token 间按 Aij∼Bern(σ(qiᵀkj)) 采样邻接阵作注意力掩码（Gumbel-softmax 可微），Aij=1 即 st_j 为 st+1_i 的局部父结点；多层用路径矩阵 Ā=(AL+I)…(A1+I)（+I 对应残差）抑制多跳信息泄漏。干预建模：可学习干预 token 码本与对象 token 一起输入，路径为零则非干预目标；测试时对连续 token 梯度下降即可适配未见环境（含已见干预组合）。目标 min E[L(ŝt+1)+λs|Ā|]，λs 经拉格朗日松弛调度。理论依据为稀疏机制转移假设。

  • 主要命题/定理：无形式化定理。数据：Interventional Pong、CREATE（二维物理）、Traffic（Waymo 真实数据，图对人工标注）。结果：结构汉明距离（SHD）三域 1.51/1.17/6.84，对 Transformer 基线 6.37/6.29/10.6、全局图基线 5.42/8.77/—，预测误差持平；移除非因果实体后误差变化 24.5%/28.6%/13.9% 对 Transformer 1140.2%/138.2%/32.8%；5 条轨迹少样本适应（含未见组合干预）误差一致最低。

  • 在因果研究脉络中的角色：因果表示学习纲领与独立因果机制（ICM）/SMS 假设在世界模型的落地：注意力掩码即局部因果图、环境索引用干预 token 实现，把 do-操作的组合性内嵌进架构；首次把局部因果发现从标量状态推广到对象嵌入场景。

  • 本文自认的局限/未来工作：(1) 未对场景组成可变时局部图的可识别性给理论陈述，需探索识别条件；(2) 自适应限于学到的干预空间，全新行为（球瞬移）无对应 token，提出借鉴域随机化程序化生成受干预环境；(3) 依赖预解耦对象表征（评测用真值掩码），值得研究局部稀疏能否促使解耦因果表征涌现。
