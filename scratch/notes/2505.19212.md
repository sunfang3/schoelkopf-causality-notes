## 2505.19212 When Ethics and Payoffs Diverge: LLM Agents in Morally Charged Social Dilemmas
- 作者/日期/来源：Steffen Backmann, David Guzman Piedrahita, Terry Jingchen Zhang, Emanuel Tewolde, Rada Mihalcea, Bernhard Schölkopf, Zhijing Jin（ETH/多伦多 Jinesis Lab/CMU/密歇根/MPI 图宾根）；2025-05-25（v2 2026-07-24）；arXiv:2505.19212
- **一句话定位**：提出 MORALSIM 仿真框架，把囚徒困境（PD）与公共物品博弈（PGG）嵌入三种道德情境，使道德行为与收益最大化直接对立，用随机化全因子实验与平均处理效应（average treatment effect, ATE）估计量化九个 LLM 智能体道德行为的因果驱动因素。
- **研究问题**：LLM 的道德判断与博弈行为此前被分别研究；当道德义务与自身利润直接冲突时（RQ1 智能体如何在博弈结构、道德情境、生存风险间权衡道德与收益；RQ2 如何随对手行为调整；RQ3 哪些因素因果地驱动道德选择、对提示改写是否稳健），LLM 智能体会如何行动？
- **模型与方法**：在扩展 GovSim 框架的两智能体重复博弈中，每轮先行动（PD 选合作/背叛；PGG 选捐献额 c_i∈[0,E]，收益 p_i=E−c_i+(aΣ_j c_j)/N，1<a<N）后反思；智能体有近三轮记忆、无对话。三种道德情境使合作即道德：合同申报（Contractual Reporting，如实报告合资收入）、隐私保护（Privacy Protection，是否用侵犯隐私的数据训练）、绿色生产（Green Production，环保配方与安全设施捐献），另有中性 BASE。实验为 GAME×CONTEXT×SURVIVAL×OPPONENT 的 2×4×2×2 全因子设计（32 配置），对手为始终合作/始终背叛；温度尽量取 0，每配置 5 个随机种子。指标：相对收益 r_i（按可行最优/最差收益归一）、合作分 m_i（PD 为合作轮占比，PGG 为平均捐献比例）、存活率 s_i、对手追随度 o_i。因果识别靠随机化：ATE_F=E[Y(1)−Y(0)] 按因子取值在其余因子所有组合上求 run 级平均差，双样本 t 检验加 95% 置信区间；CONTEXT 以 BASE 为参照做逐对比较。模型共九个：推理类 DeepSeek-R1、o3-mini、Qwen-3-235B-A22B，非推理类 Claude-3.7-Sonnet、DeepSeek-V3、Gemini-2.5-Flash-preview、GPT-4o-mini、GPT-4o、Llama-3.3-70B。
- **主要命题/定理**：无定理；核心经验结果（Table 1/2，Figure 3/4）：(1) 无模型在所有情境保持一致道德，情境化合作率 7.9%（Qwen-3-235B）至 76.3%（GPT-4o-mini），道德框定普遍抬高合作同时压低相对收益（如 GPT-4o 收益 79.8→32.3）；(2) ATE 显示博弈结构与道德框定是最一致的因果驱动：PGG→PD 使合作下降 10.3–45.2 个百分点（九模型全部显著），BASE→合同申报提升 20.7–55.2 pp，绿色生产次之，隐私保护最弱（部分不显著，如 DeepSeek-R1 +1.1）；对手合作→背叛大幅压低条件合作型模型（Claude-3.7-Sonnet −47.4 pp）；生存压力效应异质（o3-mini −24.4 pp，多数不显著）；(3) 行为对提示改写稳健（3 种改写在 GPT-4o 与 DeepSeek-R1 上合作分平均仅移 1.8±2.4 pp）；(4) 对每模型约 3500 条反思轨迹用自动标注器（动机分类法改编自 Piedrahita et al. 2025）做动机画像：DeepSeek-R1 以收益最大化（67%）与纳什均衡推理（50%）为主，Claude-3.7-Sonnet/GPT-4o 道德（41%/36%）与声誉（46%/37%）占比高，Llama-3.3-70B 风险规避突出（44%），动机档案与行为一致。
- **在因果研究脉络中的角色**：属 Schölkopf–Jin 组"因果方法×LLM 评测"主线的实证支线：不构造 SCMs，而是用因果推断的实验设计面（随机化全因子 + ATE + 置信区间）把"哪些因素塑造 LLM 道德行为"变成可检验的因果问题，呼应组内用因果工具系统评测大模型的主张（与 2502.05085 同一议程的实验化）；也与公平性/可信 AI 关心的"情境脆弱性"相衔接。
- **本文自认的局限/未来工作**：(1) 仿真必然抽象于真实部署——道德显著性、个人利害、对手可观测性与行动时序均不同于每轮后全透明的设定；(2) 温度固定为 0 以保证可复现与干净的因果识别，不代表生产环境随机解码，非零温度对道德行为的影响留待未来；(3) 改善道德一致性的方法（定向提示、基于偏好的微调、智能体间机制设计）是留待未来的重要方向；(4) 只研究两种典型困境，协调型（猎鹿）、序贯（信任博弈）、非对称（Bach or Stravinsky）等结构可能显现不同道德张力；(5) 仅两智能体交互，多智能体情境下的社会推理、涌现动态与共同道德责任待考；(6) 智能体间无自由文本对话，沟通如何改变合作留作扩展。
