## 2608.27510 How Do Linear Probes Emerge? A Circuit-Tracing Framework with Concept-Targeted Attribution
- 作者/日期/来源：Vedant Palit, Florent Draye, Terry Jingchen Zhang, Bernhard Schölkopf, Zhijing Jin（多伦多大学 Jensis Lab/Vector、EuroSafeAI、MPI 智能系统研究所、Hector Foundation、ELLIS Tübingen），2026-08-27，arXiv:2608.27510
- **一句话定位**：提出概念定向归因（Concept-Targeted Attribution, CTA），把跨层转码器（Cross-Layer Transcoder, CLT）归因图的解释目标从下一词元 logit 替换为线性探针方向，从而把"探针为何能解码某概念"还原为稀疏电路层面的因果机制，并用消融证明概念编码与 token 生成是功能可分离的两套计算。
- **研究问题**：线性探针只是诊断工具——它回答某概念在某层是否线性可解码，不回答哪些稀疏特征支撑检测、探针性能为何随层与 prompt 变化、概念检测与 token 生成路径关系如何（例如中性框架包装的毒性引文：模型内部表示了毒性但生成安全的续写）。
- **模型与方法**：CLT 用稀疏特征重建 MLP 输出（式(1)：MLP_ℓ(x_ℓ) ≈ Σᵢ f_{ℓ,i} d_{ℓ,i} + b_ℓ），跨层解码矩阵 W_dec^{ℓ→ℓ′} 允许早层特征直接解释后层输出，使归因可沿线性路径追踪；归因图以（层,位置,特征）为节点、经冻结非线性（stop-gradient）的局部线性 Jacobian 加总的归因分数（式(2)）为边，剪枝保留累计 80% 特征效应与 95% 边效应。CTA 仅改目标：解释探针得分 S_θ̄(x_ℓ) = θ̄ᵀx_ℓ，其中方向取均值差（difference-in-means, DIM）W_c = (μ₊−μ₋)/‖μ₊−μ₋‖，评估时另用 PCA-200 子空间内 LDA（IID）校正方向。四个概念与数据：毒性（ParaDetox 平行毒性/去毒句对，隔离意图而非关键词）、情感（SST-2）、推理（HotpotQA 多跳 vs TriviaQA 单跳）、真实性（Geometry of Truth 三子集合并）；每类 n=5000、≤60 token、80/20 划分。单层图锚定在"信念层"（belief point）L_b：平均正类探针得分单步上升最陡且落在峰值 2–8% 平台内的层（Gemma-2-2B：毒性 L22、情感 L21、推理 L15、真实性 L14；对应验证准确率 90.0/80.1/87.6/88.2%），避免残差流"被动携带"早层信息造成的高准确率假象。
- **主要命题/定理**：无形式化定理，核心是三条实验结论（主实验 Gemma-2-2B，Llama-3.2-1B 于附录 D 复现）。其一，因果双分离（causal double dissociation，表1/4）：对每 prompt 同时构建探针图 G_probe 与 logit 图 G_logit，消融探针专属节点 G_probe∖G_logit（约 130–203 个）使探针得分骤降（毒性 ΔS=−61.24、情感 −40.42）而 top-1 生成翻转率≈0%（仅真实性 25%）；消融 logit 专属节点（约 297–539 个）在 92–100% 的 case 中改变生成 token 且 ΔS≈0。真实性分离较弱（共享子图依赖更大）；推理的 L15 探针与全部测试 prompt 反对齐（基线 S=−21.44），ΔS 符号反转但定性模式保持。其二，图结构预测探针质量（表2）：35 个图结构特征（全局/节点统计/拓扑三族）按（概念,层）对 prompt 平均后，梯度提升回归在 5 折组感知交叉验证下预测该层探针验证准确率，Spearman ρ=0.91±0.05、R²=0.84±0.14（层深基线 0.08±0.15；bootstrap 95% CI [0.724,0.964]，200 次组级置换 p<0.005），高准确率层表现为更高的影响力集中度（Gini）、最大 CLT 激活、最大边权与图密度（图3，Cohen's d=+0.88~+1.68）。其三，特征级与稳定性：以 top-100 CLT 特征的 0/1 存在性经 Ridge 回归可预测逐 prompt 探针 margin；识别出概念特异特征如毒性的 L0/F8116（贬损心智能力语言）、真实性的 L9/F2578（地理错配类虚假标记，"虚假检测器"强于"真值检测器"）、推理的 L11/F9661（二元比较句式，Fisher p<0.001）；top 预测特征出现率为随机特征的 6–21 倍（"多电路、一核心"，图5）；相邻层图 Jaccard 自 L8–12 后稳定于约 0.9（图6）。
- **在因果研究脉络中的角色**：属 Schölkopf 组近年机制可解释性（mechanistic interpretability）支线，工具与人员直接承接同组 CLT-Forge 库（Draye et al. 2026）与稀疏注意力后训练（Draye et al. 2025）工作。因果脉络上，本文把探针从行为学相关诊断转为干预/消融的因果对象：对"内部概念表示"与"输出生成"两类变量做经典 Teuber 式双分离，可视为独立因果机制（ICM）思想在 LLM 内部计算上的实例检验，也与因果表示学习（causal representation learning）中"表示本身作为因果分析对象"的立场呼应；毒性审计动机延续其在 AI 安全方向的应用兴趣。
- **本文自认的局限/未来工作**：(1) CTA 继承底层 CLT 的质量——被 CLT 混淆、遗漏或多义表示的特征对归因图不可见，稀疏–重建权衡塑造进入电路的特征且无概念特定调参；(2) 线性探针是概念有效性的必要非充分条件——在相关标签分布上训练的探针可能捕捉文体而非概念特征；(3) 特征存在性分析丢弃激活幅度，会漏掉判别信号位于激活几何而非特征同一性的概念；(4) 未来工作：更广的跨架构复现、面向细粒度概念导向（steering）的更深干预实验、扩展到四个概念之外更丰富的概念分类学。
